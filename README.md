# ⚡ X7 Enhancement Simulator

X7 게임의 **강화 시스템**을 시뮬레이션하는 웹 앱입니다.
델피나드 기운(천장 시스템) + 복구 메커니즘을 포함한 확률 기반 시뮬레이터.

🚀 **[라이브 데모 바로 가기]** ← *(배포 후 URL 입력)*

---

## 기능

| 탭 | 설명 |
|----|------|
| 🎮 **인터랙티브** | 클릭으로 강화 직접 진행. 기운 게이지·복구 소모·예상 노강 실시간 표시 |
| 📊 **배치 통계** | N회 일괄 시뮬 → 시도 분포 히스토그램·분위수 테이블·7개 티어 비교 |
| 🔬 **몬테카를로 테이블** | 복구 포함 예상 노강 소모 기댓값 전체 테이블 + 히트맵 |

### 강화 시스템 규칙
- **+4 ~ +10**: 실패 시 단계 유지 (No-drop)
- **델피나드 기운**: 실패마다 기운 충전, 100% 도달 시 다음 강화 **100% 보장** (천장)
- **복구**: 강화 3회 실패 소진 시 현재 강화 단계 동일 아이템 1개 소모 후 3회 리셋
- **성공 시**: 강화 횟수 3회로 리셋

## 로컬 실행

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 앱 실행
streamlit run enhance_app.py
```

## Streamlit Cloud 배포

1. 이 저장소를 GitHub에 Push
2. [share.streamlit.io](https://share.streamlit.io) 접속
3. **New app** → 저장소 선택 → Main file: `enhance_app.py`
4. **Deploy!**
